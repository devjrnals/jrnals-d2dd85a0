# Font Files Directory

Place your ABC Oracle font files here:

- `ABC-Oracle-Regular.woff2` (or `.woff`)
- `ABC-Oracle-Medium.woff2` (or `.woff`)
- `ABC-Oracle-Bold.woff2` (or `.woff`)

## How to add the font files:

1. Download ABC Oracle font files from Dinamo
2. Convert to `.woff2` format (recommended) or use `.woff`
3. Place the font files in this `public/fonts/` directory
4. The font will automatically be available as `font-oracle` in Tailwind classes

## Usage:

- In Tailwind: `className="font-oracle"`
- In CSS: `font-family: 'ABC Oracle', sans-serif;`
- In inline styles: `style={{ fontFamily: "'ABC Oracle', sans-serif" }}`
